# 📚 Ktabna - Web Presentation

Présentation web professionnelle du système de gestion de bibliothèque **Ktabna**.

## 🚀 Démarrage Rapide

### Ouvrir la Présentation

```powershell
# Ouvrir dans le navigateur
start index.html

# Ou simplement double-cliquer sur index.html
```

## 🎮 Contrôles de Navigation

- **Touches fléchées** `←` `→` : Naviguer entre les slides
- **Space** : Slide suivante  
- **Home** : Premier slide
- **End**: Dernier slide
- **Boutons** : Cliquer sur les flèches en bas à droite
- **Mobile** : Swipe gauche/droite

## 📊 Structure (15 Slides)

1. **Hero** - Titre et présentation générale
2. **Projet** - Objectifs et stack technique
3. **NoSQL** - Pourquoi MongoDB ?
4. **Schémas** - Collections MongoDB
5. **CRUD** - Opérations sur la base de données
6. **Architecture** - Structure de l'application
7. **Fonctionnalités** - Admin & Utilisateurs  
8. **Statistiques** - Graphiques interactifs
9. **Conclusion** - Points clés et résumé
10. **Comparaison Schémas** - SQL (7 tables) vs NoSQL (2 collections)
11. **Comparaison Requêtes** - SQL vs MongoDB côte à côte
12. **Tableau Comparatif** - 10 aspects détaillés
13. **Opérateurs MongoDB** - $push, $pull, $inc, etc.
14. **Avantages & Limitations** - Analyse complète
15. **Déploiement** - Cloud, i18n, fonctionnalités futures

## ✨ Fonctionnalités

- Design moderne avec glassmorphism
- Animations fluides
- Graphiques Chart.js interactifs
- Navigation clavier, souris et tactile
- Responsive (desktop, tablette, mobile)
- Progress bar & slide counter  
- Deep linking avec URL hash
